## 프로젝트 개요

분석 데이터는 **7,000건 × 18개 컬럼**으로 구성되어 있습니다. 나이, 신장, 체중, BMI, 시력, 충치, 공복 혈당, 혈압, 중성지방, 콜레스테롤 계열, 헤모글로빈, 요 단백, 간 효소율과 흡연 여부를 사용했습니다.

흡연 여부 분포는 다음과 같습니다.

| 구분 | 인원 | 비율 |
|---|---:|---:|
| 비흡연 | 4,429 | 63.27% |
| 흡연 | 2,571 | 36.73% |

분석 목표는 흡연 여부를 기준으로 건강 지표의 차이를 확인하고, 시각화를 통해 어떤 지표가 흡연과 함께 변하는지 파악하는 것이었습니다.

## 전처리

BMI와 나이를 구간화해 범주형 파생변수를 만들고, 결측값은 변수 특성에 따라 다르게 처리했습니다.

| 변수 | 결측 | 처리 |
|---|---:|---|
| 혈압 | 140 | 중앙값 |
| 시력 | 140 | 최빈값 |
| 중성지방 | 140 | 나이대별 평균 → 남은 값은 전체 평균 |
| 공복 혈당 | 140 | 전체 평균 |

BMI 구간은 저체중, 정상, 비만전단계, 1·2·3단계 비만으로 나눴고, 나이는 연령대로 구분해 분포를 비교했습니다.

## 주요 결과

### 1. BMI가 높은 구간에서 흡연자 비율이 대체로 높았습니다

| BMI 구간 | 흡연자 비율 |
|---|---:|
| 저체중 | 28.3% |
| 정상 | 30.6% |
| 비만전단계 | 39.6% |
| 1단계 비만 | 41.8% |
| 2단계 비만 | 46.0% |
| 3단계 비만 | 43.9% |

마지막 3단계 비만 구간은 표본이 41명으로 작기 때문에 전체 추세를 해석할 때 주의가 필요합니다.

### 3. 중성지방 차이가 가장 뚜렷했습니다

| 지표 | 비흡연 | 흡연 |
|---|---:|---:|
| 중성지방 평균 | 113.45 | **150.40** |
| 중성지방 중앙값 | 97 | **131** |
| BMI 평균 | 23.81 | **24.73** |
| 혈압 평균 | 45.42 | 45.76 |
| 혈압 중앙값 | 45 | 45 |

혈압은 두 집단의 평균과 중앙값이 거의 비슷했습니다. 반면 중성지방은 평균과 중앙값 모두 흡연자 집단에서 높게 나타났습니다.

### 4. 상관관계에서도 중성지방이 가장 크게 나타났습니다

최종 분석 Notebook에서 흡연 여부를 0/1로 변환한 뒤 계산한 Pearson 상관계수입니다.

| 변수 | 흡연 여부와 상관계수 |
|---|---:|
| 중성지방 | **0.25** |
| BMI | 0.13 |
| 충치 | 0.10 |
| 혈압 | 0.02 |

상관계수는 변수 간 동반 변화의 정도를 보여줄 뿐, 흡연이 해당 지표의 원인임을 증명하지는 않습니다.

## 분석 흐름

```text
7,000건 건강검진 데이터
        ↓
데이터 구조·결측 확인
        ↓
BMI / 연령대 파생변수
        ↓
결측값 처리
        ↓
단변량 분포 확인
        ↓
흡연 여부별 비율·평균 비교
        ↓
상관관계 시각화
        ↓
건강 인사이트와 한계 정리
```

## 한계

이 분석은 관찰 데이터 기반이므로 인과관계를 판단할 수 없습니다. 발표 자료에서는 혈압 데이터의 성격, 성별 정보 부재, 흡연자·비흡연자 및 연령대 표본 불균형, 생활 습관 변수 부재를 주요 한계로 정리했습니다.

따라서 결과는 **이 데이터에서 관찰된 패턴**으로 해석하는 것이 적절합니다.
